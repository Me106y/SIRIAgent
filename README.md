# SIRIAgent

遥感任务与星历服务：在一个页面里看卫星现在在哪、飞过哪、能不能拍，并让 Agent 直接给出过境结论与成图方案。

**在线使用：<https://siriagent.dpdns.org>**（Cloudflare Access 保护，账号需管理员授权）

![SIRIAgent：左侧卫星目录、中间 3D 地球、右侧 Agent](docs/assets/frontend.png)

## 能做什么

### 星历可视化

- 65 颗国产遥感卫星的实时星下点，每 5 秒刷新；左栏可按名称 / NORAD 搜索，按商业、民用、气象海洋筛选。
- 选中一颗星，中间地球画出它未来 2 小时的星下点轨迹与当前传感器足迹（按幅宽折算）。
- 选中星详情给出类别、轨道、TLE 年龄、载荷是否公开，以及未来 24 小时过境（AOS、最高仰角、光学是否可用）。
- 「聚焦」把相机飞到选中星足迹；「杭州」飞到杭州并让市界多边形闪烁约 6 秒。

### 与 Agent 对话

- 用自然语言问位置、过境、载荷、TLE 新鲜度，或让它分析一份成图方案。
- 思考过程、工具调用与结果随回答展示；回合结束后折叠成「工作步骤 · N 步 · X s」，点开可看完整时间线。顶栏设置可切换极简 / 简洁 / 标准 / 详细 / 完全展开五档，默认极简。
- 隧道断线时自动用同一回合续读，不会把正在跑的回答丢掉，也不会把 Agent 的追问当成「用户没回答」。
- Agent 需要澄清时弹出单选 / 多选卡片，选完继续同一轮。
- 输入 `/` 打开技能菜单，目前有 `/ephemeris-query`、`/pass-planning`、`/tle-health`。
- 输入框下方可选模型（Flash / V4 Pro）与推理程度（关闭 / 低 / 高 / 最高），默认 Flash + 低，选择记在浏览器本地；切换模型会保留当前会话。
- 顶栏显示 DeepSeek API 余额，点击可刷新；「新会话」清空当前上下文。

![对话：思考、工具步骤与带精度声明的回答](docs/assets/chat.png)

### 卫星成图

点右栏「卫星成图」打开五步向导：

1. **任务**：最少星达到覆盖率（面积口径，默认 90%）、最少星达到重访、给定星数最大化覆盖面积（面积口径）、给定星数最小化面积分位 MRT、给定星数最小化 ART。
2. **范围**：浙江省内的省 / 市 / 区县，或在地图上手绘多边形。
3. **时间窗**：1–168 小时；task1 可先试当前窗口，不达标再自动扩到 72 小时。
4. **约束**：传感器类型、分辨率上限、指向模式、面积目标、覆盖率、P95 重访上限、星数预算、网格大小、检测步长与选星时限。
5. **求解与报告**：轮询求解进度，给出选中卫星与达标面积；生成四节 HTML 报告（卫星构成 / 覆盖与回放 / 推荐计划 / 口径与精度）。报告可切换深 / 浅主题、导出 PDF，也能一键让 Agent 继续解读。

报告里的过境表给出每次过境的「平均覆盖 / 最大覆盖」，含义与统计口径写在报告的「口径与精度」一节。

## 怎么用

1. 打开 <https://siriagent.dpdns.org>，通过 Cloudflare Access 登录（账号需管理员授权）。
2. 左栏选一颗卫星；中栏看轨迹与足迹，或点「聚焦」「杭州」调整视角。
3. 右栏直接提问，或在输入框打 `/` 选技能；也可以点示例问题快速开始。
4. 要规划成像时点「卫星成图」，按向导提交；求解完成后生成报告。
5. 想让 Agent 解读报告，点报告区的分析入口，对话会自动带上报告路径。

可以这样问：

- 杭州明天有哪些卫星过境？
- GF-2 现在在什么位置？
- 未来 24 小时杭州有哪些光学成像窗口？
- 帮我看看最新这份成图方案，覆盖薄弱区在哪、选星是否合理。

## 数据与精度

- 卫星目录 65 颗国产遥感卫星（61 颗光学 + 4 颗高光谱）；SAR 缺原生入射角带，暂不参与成图。
- TLE 每天 03:00 从 CelesTrak 同步一次；年龄 >72 小时标记精度下降，>7 天拒绝用于过境计算。
- 可见性门限 5°；成像要求最高仰角 ≥10°，光学另需太阳高度 >10°。
- 所有结果带 `accuracy_note`：SGP4 在 LEO 沿轨误差约 1 km/天，过境时间约 ±1 分钟；覆盖率与重访是估算值，足迹边缘误差按 ±2–5 km 对待。
- 结论只用于可视化、可行性初判与任务规划，**不能用于亚米级任务或碰撞规避**。

## 已知限制

- 同一时刻只跑一轮对话（进程内串行），多人同时使用需要排队。
- 没有应用层账号、配额或多用户隔离，访问控制依赖 Cloudflare Access。
- 成图任务状态在 RS-Service 进程内；服务重启会丢失排队中的任务，已生成的报告文件保留。
- 成图范围仅限浙江省内；目录里没有 SAR 星。
- 回答在回合结束时整块返回，不是逐 token 流式。
- 移动端只保证可读降级，没有专项适配。
