# Pass Planning

1. 明确 AOI（默认杭州 30.27N, 120.16E）和时间窗（默认未来 24 h）。
2. 调用 `next_passes`，需要多颗星时先 `list_satellites` 再筛选。
3. 可见性门限 5°；光学成像要求最高仰角 ≥10° 且 TCA 太阳高度 >10°；SAR 不看太阳。
4. 输出 AOS/TCA/LOS（北京时间）、最高仰角、时长、太阳高度、是否可成像。
5. 说明过境时间误差约 ±1 分钟，足迹边缘误差约 ±2–5 km，未计云量。
